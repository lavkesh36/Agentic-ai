# Agentic-ai
This repo about learning the agentic ai

## Getting Started

1. Run the starter agent:

```bash
python3 run_agent.py
```

2. Explore the files:

- `agent.py` - simple agent model with perception, planning, action, and reflection.
- `run_agent.py` - example script that creates an agent, sets a goal, and runs it.

3. Modify the goal and experiment with different plans.
